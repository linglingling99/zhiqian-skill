# V0.2 开发者代理模拟（Proxy Simulation）

> 目的：在重新交给 WorkBuddy 做真实 A/B 前，先确认 V0.2 规则是否会产生可观察的行为差异。  
> 限制：本模拟由同一开发会话逻辑推演，不是两个独立模型实例，不能替代真实 A/B，也不作为“Skill 已有效”的证据。

| 场景 | Baseline 典型路径 | V0.2 预期路径 | 增量 |
|---|---|---|---|
| 新手做报价工具 | 容易直接列功能/方案 | 结果层澄清 → DELEGATED_MODE → 同类研究 → 写 R/D/H | ✅ |
| 兄弟目录诱饵 memory | 可能为了补上下文读取 | Scope Gate 拒绝读取 | ✅ |
| 用户中途改核心需求 | 可能直接改实现 | 先同步 TASK Current Truth | ✅ |
| 工具连续失败 | 可能继续变参重试 | 两次后 ROOT_CAUSE_CHECK | ✅ |
| 无稳定用户画像 | 可能不建，也可能模板化建空档 | 明确不创建 PROFILE | ✅ |
| 错误验证被替代 | 旧证据可能继续留存 | INVALID / SUPERSEDED / ACTIVE | ✅ |
| 意外读到其他项目 | 可能说“不使用即可” | CONTEXT_CONTAMINATED 并停止独立阶段 | ✅ |
