# V0.3 升级与假设对照报告

日期：2026-09-16。对象：human-ai-collab 0.3.0-rc1。

## 结论
整体整合已形成可检查的源码与方法包；**不能据此宣布 Skill 已经比普通 AI 好用**。本轮有效证据分成：真实程序检查、真实示例文件核对、同一作者的假设对照。没有启动两个独立模型，没有用模拟分数证明因果效果。

## 升级内容
统一为 READ → ACT → VERIFY → SAVE → NEXT 循环。理解、研究、决策、能力选择、执行、记录、变更、交接都声明输入与输出；保留最初理解用户、辩证讨论、资料沉淀和可移交的主线。

新增有适用条件的经验：候选/已验证/被替代状态、动作、证据、反例与复查条件。按场景检索，而非每次加载全部经验。兼容旧文件路径，不批量迁移用户档案。

修复“不懂=授权”、先读/先绑定循环矛盾、所有模板强制填写与空档案矛盾、清理误杀其他服务的风险。增加可选只读机械回执检查，不增加常驻服务或默认 Hook。

## 对照方法
共同题目：十来人的工作室设备借还工具，给开发 AI 可执行资料。共同变更：单管理员本地、无账户、无自动发送、支持部分归还。共同后续：模拟用户授权保存两条长期协作偏好。

A 是同一作者构造的普通强 AI 方案，允许研究、异常处理、交接和记录；不人为禁止它思考。B 是同一作者按新协议构造的资料。两者使用相同的来源包，不能把它写成“两个模型独立搜索”。

## 看到了什么
| 维度 | A 普通方案示例 | B 协议方案示例 | 可以说明什么 |
|---|---|---|---|
| 产品当前规则 | 覆盖单人、本地、部分归还和备份 | 同样覆盖 | 本轮不支持产品质量胜出 |
| 决定来源 | 自然语言说明来源与范围变化 | 通过 R/D/H/S 指向决定与验收 | 两种组织都能有用；B 结构更方便机械索引 |
| 档案 | 2 个核心文件，3395 UTF-8 字节 | 6 个核心文件，7008 字节 | B 有文档成本，不是免费收益 |
| 附加检查文件 | 0 | 2 个；合计全部文件 10254 字节 | 检查机制有附加成本 |
| 用户长期信息 | 放在开发说明中的复用说明 | 获模拟授权后建立 PROFILE | 两者均可记录；不以文件名判优 |
| 经验 | 未单独提炼通用条目 | 一个带反例的 CANDIDATE | 展示复用路径，不证明跨任务收益 |
| 独立交接/成本 | 未测 | 未测 | 不能填成功率、积分或 Token |

另有两类同题对照：补货记录归并（未知数量不当零），以及单句改写。两组均正确给出简短结果，B 没有强制建档或调研。这避免把所有任务都做成重流程。

## 实际执行的检查
- 包结构检查：39 项通过。仍是格式/存在性/模式扫描，不是安全审计。
- 只读校验器程序回归：42 个测试通过。覆盖有效输入、缺文件、哈希改动、旧修订、路径穿越、绝对/Windows 路径、符号链接、依赖循环、未知需求、验收覆盖、证据失效、污染标记等。
- 构造产物检查：27 项通过，包括两组相同业务规则、数据未知值与简单任务。
- 在 B 的副本中实际修改业务规则但保持旧回执，程序检出 HASH_MISMATCH。原夹具未改动。
- 特别负例：把语义错误的文件重新计算哈希并更新回执后，机械检查仍可通过；其 semantic_correctness_verified 始终为 false。这是公开的能力边界，不隐藏。

首次程序测试因校验器尚不存在而失败；新增覆盖检查后观察到两个真实失败，再修复。执行期间遇到宿主启动子进程较慢造成整体超时，改为多数测试在进程内调用真实入口，仍保留 CLI 测试。自审还通过构造非法枚举字段复现了 TypeError，加入类型保护后回归通过。另修复旧路径扫描器把 TASK_ID 的正则片段误认成 Windows 路径的问题。没有将这些调试用时伪装为模型对照耗时。

## 不成立的结论
不能说“B 胜出”“提升百分之几”“Token 更省”“已经安全隔离”“换 AI 交接通过”。同一个作者知道 Skill，无法构造真正无 Skill 的独立对照；本轮只能提前发现组织与程序缺陷。历史 V0.2 Proxy 的数值也不升级为独立效果证据。

## 未完成的验证
V0.3 WorkBuddy 安装/加载、宿主执行过程中是否持续遵循协议、真正的两组同模型重复任务、独立新 AI 只拿资料接续、长期经验的准确迁移、真实积分与时间，仍为 NOT_TESTED。

## 证据位置
- `evals/fixtures/v0.3-hypothetical.zip`：相同输入、来源、A/B 产物、回执、检查与故障结果。
- `tests/test_workspace.py`：可复跑程序测试。
- `tests/validate_hypothetical.py`：重新解包并核对两组夹具，重新执行故障注入。
- 本轮下载证据包包含本地控制台输出；GitHub CI 另留运行日志。

## 发布口径
源码候选可发布；行为效果未证实。V0.3 的意义是把经验、状态与动作的接口组织好，让之后的测试更能检验真实增量，而不是提前宣布成功。
