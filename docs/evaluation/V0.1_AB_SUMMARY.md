# V0.1 A/B 真实测试摘要

> 目的：记录 V0.1 在真实 WorkBuddy 环境中的第一轮对照结果。这个文档不是宣传材料，而是下一版修复的证据基础。

## 测试方式

- 同一 WorkBuddy 环境与同类模型配置；
- 两个隔离会话、独立工作目录；
- 相同原始任务；
- 用户尽量不做产品经理，只在必要时回答，更多使用“你自己判断/你看着办”；
- A：Baseline，无 `human-ai-collab`；
- B：安装 `human-ai-collab` V0.1；
- 最终对比产品、时间、工具调用、失败/返工、用户负担、文件沉淀、可交接准备度与事故记录。

## 关键结果（同口径）

| 指标 | Baseline | Skill V0.1 |
|---|---:|---:|
| 工作窗口 | ≈23m44s | ≈21m34s |
| 首个经验证可用成果 | ≈18m14s | ≈15m45s |
| AI 主动提问 | 3 | 2 |
| 工具调用 | 58 | 90 |
| 失败动作 | 3 | 10 |
| 返工 | 4 | 8 |
| 用户负担（自审） | 2/10 | 1/10 |
| Handoff readiness（自审） | 82/100 | 82/100 |

Credits / Token 无法从宿主获得可靠真实值，因此未做估算。

## 产品结果

两组最终产品各有优势，没有出现“装 Skill 后明显更强”的结果：

- Baseline 更偏轻量、灵活、国际化、立刻可用；
- Skill 组在商务字段、阶段化产品路线、需求/假设/决策结构上更完整；
- 单看最终产品质量，V0.1 没有证明显著领先。

## V0.1 证明了什么

有正向信号：

- 需求 / 偏好 / 事实 / 假设 / 决策分层更明确；
- 能主动识别“尽快简单”与“云端/账号/分享”等需求之间的冲突；
- 用户需要回答的问题更少；
- AI 更愿意承担低风险产品决策。

## V0.1 没证明什么

- 没证明最终产品更好；
- 没证明工具/时间净效率更高；
- 没证明可复用资产明显更多；
- 没证明真实跨 AI 交接更强；
- 数据沉淀存在“说了要写，但文件没有稳定同步”的问题。

## 严重缺陷：Scope / 数据污染

测试期间发生跨组上下文读取。核心教训：

> **路径在授权父目录里，不等于数据属于当前任务。**

因此 V0.2 把 Scope Firewall、数据归属和污染停止规则列为 P0。

## 结论

- **测试：成功。** 它真实暴露了增量和缺陷。
- **Skill V0.1：不能定义为成功版。** 更准确是 `PARTIAL PASS / V0.2 REQUIRED`。
- V0.2 的目标不是继续堆文档，而是把“思考结构”真正转成执行、结果、状态同步、边界与交接能力。
