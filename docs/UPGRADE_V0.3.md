# V0.3 兼容升级说明

## 保留与改变
保留仓库名、Skill 名、四个原 reference 路径、五个原模板路径、用户自有文件体系与全部第三方声明。吸收 RC3 的变更传播修复，再统一为事件驱动的协作循环。新增的场景参考、经验模板和只读脚本均按需读取/运行，不安装数据库、服务或自动 Hooks。

## 安装包升级
执行 AI 先确认当前真实宿主及安装路径，记录已安装版本；备份方法包，只替换 human-ai-collab 目录中的方法资源。不要覆盖其他 Skill 或项目数据。核对 `metadata.version` / VERSION 为 0.3.0-rc1 后按宿主要求重新加载或开新会话。具体平台当前仍需真实安装验证。

## 用户资料接续
不要批量迁移所有旧任务。用户指定要继续哪一个，就在那个授权范围核对旧 TASK/LOG/INDEX；保留未知字段和历史，只补下一步必需的修订/身份/来源。旧档案没有机器回执时不判任务失败，先恢复实际状态；需要机械检查才新增回执。新的独立评估不能继承受污染聊天，只改 RUN_ID 不足以清除上下文。
